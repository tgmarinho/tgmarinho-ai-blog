Dia que foi de planejar para entregar para começar algo novo, tudo num arco só.

### Projeto cliente (NDA)

Transformei o doc de produto num PRD para o redesenho de cadastros, focado nas entidades centrais e nas tabelas de preço, que é onde a UI e a UX precisam estar certas.
Depois rodei sessões de modelagem de domínio para quebrar o trabalho em specs e tarefas que o time consegue pegar, ficando de propósito só na modelagem e nos protótipos, sem CRUD ainda.
Parte do dia foi ferramenta para isso: adicionar skills de auditoria do projeto e avaliar algumas skills open-source de review para ver se cabem nesta base de código.

### tgmarinho-ai-website

Construí um efeito de hero que eu vinha imaginando: um retrato que se preenche com partículas conforme o cursor passa por cima, revelando a imagem de um robô parte por parte.
Para proteger o LCP, ele carrega só depois que a tela termina de renderizar.
O efeito é perfumaria, então prefiro pagar o custo de uma revelação tardia a bloquear o usuário esperando por ele.
Escrevi um post tutorial de como foi feito, linkei o código no repo principal e empacotei tudo como uma skill reutilizável para quem quiser usar.

### iTOP

Preparei o produto de eventos para self-hosting com Postgres e Dokploy.
Também limpei um `force-dynamic` que eu tinha colocado ao sair da Vercel, e que era sintoma de uma chamada ao banco em build time, não uma correção de verdade.

### personal-os e um app novo

Criei uma skill global `save-to-personal-os` para que qualquer agente de código, em qualquer harness, consiga abrir um workspace e guardar o que eu pedir (docs, código, pastas) no meu personal-os, com a ideia de um symlink que funcione de qualquer lugar.
Também comecei o `broddy`, um assistente pessoal em Expo React Native construído sobre o SDK do pi.dev, pensando num modelo embarcado para não queimar os tokens do usuário.

O formato do dia me agradou: terminar o planejamento de uma coisa, entregar uma coisinha que dá gosto, e plantar a semente da próxima.
