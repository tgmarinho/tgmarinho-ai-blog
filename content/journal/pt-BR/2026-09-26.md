### skopje

Hoje foi um dia mais de investigação do que de código commitado. Passei quatro sessões mergulhando na documentação e no comportamento real de uma API externa que precisa alimentar módulos de contas a pagar e receber. A pergunta que guiou tudo foi simples: existe endpoint documentado para criar esses recursos via API, ou só pela tela?

Depois de vasculhar, conclui que não há POST documentado, então esse caminho fica descartado por enquanto. Segui então pela via de autenticação, capturando o fluxo de OAuth via code exchange e mapeando quais parâmetros a integração realmente precisa consumir.

Também organizei o ambiente de desenvolvimento com dados de teste consistentes, definindo um CNPJ específico para representar uma unidade em dev, para não correr risco de tocar em produção durante os experimentos. Essa disciplina de separar ambientes salvou várias vezes no passado e continua valendo o esforço.

Zero commits hoje, e tudo bem. Nem todo dia produtivo termina em diff. Investigação séria de API, mapeamento de contratos e validação de hipóteses são trabalho real, e sem essa etapa o código que vem depois nasce torto. Amanhã volto com contexto suficiente para começar a escrever a camada de integração de verdade, sabendo o que dá e o que não dá para automatizar.

Build in public também é mostrar os dias de reconhecimento.
