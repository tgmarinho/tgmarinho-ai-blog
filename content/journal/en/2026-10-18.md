Today was a scatter-shot day across four worktrees, but two concrete fixes landed and a few investigations opened up.

### Checkout and file handling

Two PRs merged across the e-commerce worktrees:

- **#586** moved stored file URLs over to a new environment origin. The old URLs were pointing at a stale host, so anything uploaded before the cutover was silently broken on the new environment. The fix rewrites them at read time.
- **#587** fixed a small but annoying checkout bug: while the CEP (Brazilian postal code) lookup was in flight, the buyer's keystrokes were being clobbered when the response came back. Now whatever they type during the lookup is preserved. Classic race between async hydration and user input, the kind of thing you only notice when you're the one typing on a slow connection.

### Preview deploys and sandbox

Spent some time understanding how auto deploy is wired up across environments. It clicked that the pipeline doubles as both the sandbox and the per-PR preview surface. Auto deploy was off on one of the worktrees, which explained why previews felt stale. Opened an issue to investigate properly rather than toggling things blind.

### Voice and testing

Also poked at how to test a voice feature and swap in a different voice for recording. Didn't ship anything there yet, but got my bearings on the testing path.

Six commits, four repos, mostly cleanup work that users will never notice, which is usually the best kind.
