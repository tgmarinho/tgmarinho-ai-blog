Today was a heavy frontend architecture day, with a lot of consolidation across parallel worktrees converging on the same set of commits.

### Cadastros redesign
The biggest shift: I ripped out the eight-tab layout in the cadastros module and replaced it with five sections organized as a master-detail tree. The old tabbed UI was flattening a hierarchy that is genuinely nested (groups own farms, farms own plots), so surfacing that structure directly makes the mental model click. To back it up, I wrote an integration test that covers dragging a farm from one owner to another - testing behavior, not implementation, which is where integration tests earn their keep.

### Routing and form boundary
Migrated the frontend to URL-driven routing with TanStack Router. Alongside that, I consolidated the RHF + Zod + Zustand boundary and tightened `FormControl` so the contract between schema, form state, and store is explicit instead of implied.

### Small fixes and docs
Fixed a report bug where `area_total` from a numeric contract was not being rendered in pt-BR format. Also landed a reverse-engineered product doc so the "why" of the system is written down, not just the "what."

### Exploration
Sketched UX ideas for a relationship-management module and thought through SPA-with-Vite vs Next.js on Vercel for a new project. No commits yet, just shape.
