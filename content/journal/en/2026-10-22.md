Today was a wide front across several repos, but the throughline was clear: tighten integrations and reduce double work for users.

### Agro suite (farmerville, kampala, manado, maputo, tallinn, thebes, troy)
Six PRs landed around the same cadence. The owner record now links or creates a Conta Azul client by document, so the same person doesn't exist in two places. States and municipalities store the IBGE code, which makes the autofill match by code instead of fuzzy names. On the Conta Azul reads, I switched to one-year windows and only pull what changed between full reads. On the write side, account creation moved to the synchronous API and we dropped the protocol from the payload. A small but satisfying mobile fix too: the owner chevron now sits on the right, bigger and aligned with the name. I also documented the manual OAuth callback flow end to end so the next person doesn't have to reverse-engineer it.

### itop (windhoek)
Shipped issue #594: buying several tickets in one purchase, and opening a purchase's tickets only via its access token with a single download for all of them. Shorter path for the buyer, safer link semantics.

### petra
A landing experiment inspired by an openbot look: glass header, mega-menu, and an animated SVG bot honeycomb. Fun to build between the heavier work.
