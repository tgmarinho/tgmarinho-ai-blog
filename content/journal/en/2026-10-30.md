Today was a mix of a small but important build fix and some housekeeping across a few repos.

### grayling

The main win here was a PWA bug. The `sync-sw.js` service worker was not picking up the correct database name per environment, which meant the sync layer could end up pointing at the wrong store depending on where it was deployed. I moved the generation of `sync-sw.js` into the build step so it is produced with the environment's database name baked in. It is the kind of fix that is almost invisible when it works and painful when it does not - exactly the type I want to catch before it reaches production.

### argonaut

Spent some time triaging what was still worth keeping in the repo. Removed a legacy block of code and some stale QA reports from `docs/` that had outlived their usefulness. Keeping the tree lean makes it easier to onboard future-me (and any agent I pair with) without wading through dead context.

### velvetfish

Picked up the Pluggy integration thread again and did some planning around the next task in that flow. No commits landed yet on this one - mostly scoping the next step so tomorrow I can move straight into implementation.

A quiet, productive day: one real fix, one cleanup, one setup.
