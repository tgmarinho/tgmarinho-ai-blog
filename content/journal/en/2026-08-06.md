Today was a heavy multi-workspace day, mostly split between a field-ops PWA and some personal infra plumbing.

### Field-ops PWA

The biggest wins were around offline reliability and install UX. I landed a richer PWA manifest with a native install flow, wake lock, and app badging (#210), then chased a couple of sync bugs: an N+1 read against IndexedDB when loading offline price tables, and a reconciliation issue where Dexie caches drifted after Background Sync and stalled the queue.

I also spent time on environment hygiene. `VITE_API_URL` and `VITE_APP_ENV` are now required and must use explicit values (`production`, `staging`, `development`) instead of ambiguous shorthands. Removed a hardcoded API URL fallback in dev, normalized platform synonyms, and made the "clear local data" action sweep IndexedDB per environment.

Small UX polish too: fixed the mobile header so it stays pinned, pinned the stepper under it on the new report screen (#211), and stopped the install banner from colliding with the iOS share modal.

Alongside the code, I opened a GitHub issue to track a naming inconsistency in hooks (`use-salvar-relatorio.ts` vs `useDetalheRelatorio.ts`) - kebab-case vs camelCase with no clear rule.

### Personal runtime

Replaced a dedicated clone with bidirectional symlinks between the repo and its runtime host, so neither side has to know the other's absolute path. Documented the wiring and commit conventions so future agents can find their way around.
