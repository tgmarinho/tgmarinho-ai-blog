Today was one of those days where the work spread across many worktrees but converged on a single codebase. Fourteen commits landed, each small, each addressable, each pushing the product a notch forward.

### Form resilience
The cadastros flow was losing user input on validation errors - a quiet but infuriating bug. Owner document is now optional, and forms hold onto what was typed. The install invite that silently disappeared since #348 is back; what looked like dead code was actually a regression, and the admin reset button in Settings made that clear.

### Brand and shell polish
The login screen now shows the VGR Tech signature cleanly above the Dusty mark. A themed 404 shipped - a plane that drifted off its flight plan - with QA evidence captured for the record. A new landing page framed Dusty as service-as-software: intelligence applied to strategic finance, operations, and decisions.

### Correctness and tests
Fuel type is now mandatory on aircraft registration, with the CHECK snapshot updated to match. The E2E mock for planning picked up the new field. The backend rate-limit test now fires requests in parallel, which is how it should have been from the start.

A good reminder: dead-code sweeps need a careful eye - some "unused" paths are regressions in disguise.
