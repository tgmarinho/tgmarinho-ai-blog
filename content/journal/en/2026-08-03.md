Today was a big architectural push across four parallel workspaces, all converging on the same v1 frontend. The theme: stop scattering logic and start treating features as first-class units.

### Frontend refactor

The main move was migrating the codebase to a feature-folder layout. Business services no longer live in a shared pile - they sit next to the feature that owns them (#138). "Gestão relacional" got the full treatment: feature folder, dedicated hooks, and a Zustand store (#164). "Novo Relatório" followed the same pattern with UI standardization (#163, #66), plus a follow-up pass on layout, scroll, and interaction polish.

### Dexie types extracted

Split the Dexie interfaces and types out of `db/database.ts` into a dedicated `db/types.ts` (#168). Small change, but it makes the persistence layer much easier to reason about - the schema definition stops being tangled with type declarations everyone imports.

### Next up: a shared Select

Opened a task to standardize every `Select` on `react-select`. The native selects are painful on mobile, and I want one reusable wrapper with `clearable`, `searchable`, `loading`, and contextual `disabled` - used everywhere from property lookup onward. Foundation is set; implementation lands next.

### Merges

Also pulled `main` into the relational-focused branch, keeping the newer "Novo Relatório" work from `main` as the source of truth during conflict resolution.
