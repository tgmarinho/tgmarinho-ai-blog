Today was a multi-worktree day across a client codebase, with parallel branches pulling in the same set of merges while I chased down bugs and shaped a new spec.

### Cadastros
Loosened the owner (proprietário) model so it accepts CPF as well, treating individuals as first-class alongside legal entities. Dropped the uniqueness constraint on the document field, which was blocking legitimate cases where the same document surfaces in different contexts.

### Sincronização offline
Fixed a subtle drift where activity status in the offline cache was not reconciling with the server after sync. Now the local state converges cleanly instead of leaving stale badges in the UI, which was a recurring source of confusion when reopening the app after being offline.

### Preços
Refined the price lookup so distance snaps to the next "até" faixa cleanly. The previous behavior had edge cases at the boundaries where a value would fall between tiers and return the wrong price.

### Financeiro (F11)
Kicked off a draft spec for the financial management module, mapping out what belongs in scope and what does not. Also captured meeting notes as a labeled issue so decisions are recoverable later instead of living only in chat.

A quiet, useful day: less new surface, more sharpening the edges.
