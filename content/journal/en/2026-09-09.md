Today was mostly about consolidating deployment and questioning the shape of my APIs.

### Same-origin fullstack on Railway
The big shift across several worktrees was making the backend serve the frontend directly, with the API mounted under `/api`. That removed the need for `vercel.json` and simplified CORS to a same-origin policy. Along the way I bumped `@fastify/static` to v10, optimized the frontend bundle, added a `preview:fullstack` script to validate the serving locally, and updated the docs to reflect the new topology. A small `clean` script at the root and in the backend rounds out the housekeeping.

I also spent time reading Railway's pricing model - per-second CPU, memory, volumes, and egress - and thinking through how PR previews look now that the stack collapsed into just fullstack + Postgres.

### Contract-first with oRPC
In `chisinau` I dug into oRPC's contract-first docs and the Next.js SSR + TanStack Query playground. The pain point is real: too much duplicated code between frontend and backend that a shared contract would collapse. SSE support is an added bonus worth exploring.

### Skills, versioned
Bootstrapped `santo-domingo` with README + AGENTS.md (and CLAUDE.md as a symlink), and started standardizing on skills.md conventions so the same skills work across multiple harnesses.

### Financeiro prototype
Landed a Contas a Receber prototype with invoicing and a Conta Azul integration hook.
