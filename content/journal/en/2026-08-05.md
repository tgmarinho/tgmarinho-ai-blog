Today was heavy on backend hardening and PWA craft across a field-ops project, plus a small detour into content on the personal site.

### Field-ops app

The bulk of the day. Landed a richer PWA experience: a proper manifest, a self-owned install flow (including the iOS "Add to Home Screen" walkthrough that Safari still forces on us), Wake Lock, and app badging. Also fixed a small but annoying regression where the mobile header wasn't pinned to the top.

On the backend, I finally closed a long-running thread around offline sync and idempotency. Standardized the idempotency key across child cadastros, consolidated a Drizzle migration, and covered the retry path with tests. Report numbering is now idempotent too, so duplicate submissions from the field don't create phantom rows. Split `numero_relatorio` from `ordem_servico`, and moved prices to integer cents to stop floating-point drift.

Migrated logs from `console.*` to Pino and centralized secret redaction, which should make production logs both quieter and safer. Reorganized the backlog after the batch of merges so the next slice is clear.

I also poked at cursor-based pagination via Drizzle, decided the generated code was too clever, and stepped back to simple offset pagination.

### Personal site

Small research pass on an in-progress post about API key storage patterns, weighing a dedicated keys table versus storing on the owning entity. Leaning toward the dedicated table for the tradeoffs it unlocks.
