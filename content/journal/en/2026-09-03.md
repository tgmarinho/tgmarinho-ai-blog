Today was a heads-down day across several parallel worktrees, all converging on the same codebase. The pattern is becoming familiar: many small workspaces, one shared main branch, batched commits that land together.

### Registrations

The owner drawer got a proper overhaul. CPF/CNPJ is now required based on the person type (PF vs PJ), the layout collapses to one field per line for readability, and the address block autofills from CEP. A subtle but annoying bug also went away: selecting a município with the mouse inside the drawer no longer misbehaves, and the footer stays pinned.

### Activities (offline)

This is where most of the weight landed. Activity detail is now available offline, the agenda prefetches, and the listing revalidates on window focus. On top of that, the offline cache now reconciles activity status with the server, which closes a gap where local and remote state could quietly drift apart.

### Meta

A recurring thread today was less about code and more about workflow: pushing back on unnecessary code comments, questioning the IndexedDB quota story across browsers and devices, and thinking about how Dexie interacts with direct IndexedDB manipulation. Also drafted a demo checklist and script so the next walkthrough runs on rails instead of improvisation.

Small, boring, load-bearing progress. Exactly the kind I like.
