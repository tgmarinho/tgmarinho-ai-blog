Today spanned four codebases with a common thread: cleaning up data models and thinking hard about ownership boundaries.

### rome-v2 / stockholm-v1
Ripped IBGE codes out of the codebase and reshaped `estado` and `municipio` as read-only reference tables keyed by `uuidv7()`. No CRUD in frontend or backend for these; they're pure lookups, with room for a future `ativo` boolean if something ever changes. Since Docker is now on Postgres 18, I dropped the previous workaround for UUIDv7 and leaned on native support through drizzle-kit migrations. Also added a default admin user in the initial seed and moved the 2026 remodeling specs into `docs/new/`.

### athens / freetown
Converted the Prisma schema from MongoDB to PostgreSQL end-to-end: swapped the Docker image for Postgres 18.4, updated CI workflows and backup scripts, fixed FK delete semantics and Json null handling in the API, and isolated a permission-matrix test that was leaking state. Also trapped focus and made the background inert in `BlockingOverlay` for better keyboard/accessibility behavior. The plan is to validate the new structure locally with fake E2E data before touching real records.

### bissau
Design conversation around what happens when farm ownership transfers between owners inside the same management group: how activity plans travel, whether historical reports should follow the farm name or the id, and how to model pilots, technicians, and helpers per activity.

Read-only where possible, explicit ownership everywhere else.
