Today was a heavy day across parallel worktrees on the same product, with 32 commits landing and a lot of thinking about data boundaries and consistency.

### Offline and multi-user safety

The big fix was isolating Background Sync and IndexedDB per logged-in user on the same device, plus a migration for legacy data and stricter pilot validations. Reports now scope correctly per operational pilot, and the offline flow properly links the pilot on save. Also shipped a fix so drafts only save via the explicit button and the mobile scroll no longer jumps.

### Design system guardrails

Standardized the spacing scale and documented design system guardrails. The recurring frustration was arbitrary spacing changes across the codebase, so the fix is a consistent rule everyone (human or agent) has to follow. Small fixes to the technical team layout and modal alert actions landed alongside.

### Tooling and tests

Hardened Biome to the recommended preset plus `noExplicitAny`, and added a backend integration suite running against real PostgreSQL instead of mocks. Started sketching an end-to-end testing strategy because solo manual testing does not scale.

### Modeling and hardcode debt

Spent time mapping problems in the report data model and proposing a phased solution. The core insight: hardcoded domain values that also live in the database are a smell. The fix is a proper boolean flag on the entity, with a one-shot data migration, so business logic stops comparing strings by name.
