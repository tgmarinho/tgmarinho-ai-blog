Big day. The design system work I had been staging finally landed end to end, and most of the app now speaks the same visual language.

### Foundations to phase 3

Consolidated phases 0 and 1 as canonical foundations, then shipped phase 2 components and a phase 3 vertical slice covering trash and audit views. Added an internal `Design System` route (admin-only) so the system stays visible and buildable in memory without leaking to end users. The umbrella PR bundled fundamentals, the internal route, screen migration, and mobile polish.

### Screen migration

Migrated authentication, settings, docs, admin, dashboard, relational management, users, global components, and the report screen onto the new primitives. Standardized inputs, selects, placeholders, typography, and button contracts against the react-aria pattern from shadcn. Uppercase treatment applied to the relational management area to match the spec.

### Fixes from review

Chased focus behavior in the drawer, capturing the trigger before open and restoring focus on close. Fixed initial focus targeting, updated the pagination button to the current react-aria contract, and switched to the current unique-violation helper. Skeleton, focus-on-error, and search-input got polish passes.

### Backend

Documented API flow and layer responsibilities: where business rules live, where validation happens, where processing belongs. Standardized Postgres error codes so 23505 handling stops being copy-pasted around routes.

Icons will move behind an `icons/index.ts` barrel so swapping libraries later stays trivial.
