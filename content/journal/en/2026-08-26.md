Today was mostly about observability and small quality-of-life fixes across a private product workspace, plus some personal-OS housekeeping.

### Backend observability

The big move was landing Sentry properly on the backend: structured logs, source maps so stack traces are actually readable in production, and a scrubbing layer so sensitive fields never leave the process. I also wrote an ADR documenting the decision, both the "why Sentry logs" part and the scrubbing policy, so the next person touching this doesn't have to reverse-engineer intent from code.

### App shell and Agenda

On the client side, I removed the notifications icon from the header (it was aspirational, not functional) and taught the Agenda to display a "sent" status for the assistant's parecer. A related fix makes the parecer screens react to background sync, so the UI no longer lies about state after a silent refresh.

### CI

Disabled the automatic GitHub Actions trigger and kept verification local. Fewer noisy runs, faster loop, same guarantees when I actually want them.

### Personal OS

On the side, I versioned a batch of transcripts and consolidated a short study on "new life" from that material. Small commits, but it's the kind of thing that compounds when the folder structure is right from day one.
