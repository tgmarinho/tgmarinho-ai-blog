Today split cleanly across three fronts: infrastructure hygiene, a chunky data import, and auth hardening.

### Rate limiting behind a proxy

Spent real time unpacking `TRUST_PROXY`. The current 10 logins/minute cap applies to the whole platform, so a single team on one Wi-Fi can lock everyone out. Flipping trust on means the limiter reads the last IP the proxy wrote, which is the real one and not spoofable from outside. Documented the trade-off in `docs/RAILWAY.md` and shipped it across bismarck-v1, majuro-v1, and trenton-v2. Also fixed the app-shell 404 on URLs containing dots and made the auth test clock-independent.

### Importing a fleet of records

Built the SQL import for a fleet migration end to end: pure SQL for DBeaver, a CNPJ-keyed variant that runs in any environment, documents and models captured from the source database, aircraft models and fuel from the RAB, and documents resolved for the four owners. Cleaned up a few edge cases: grouping one record, dropping a bogus suffix, and splitting a locality by municipality.

### Blocking disposable emails

On the events platform, vendored a disposable-domains allowlist as versioned JSON so the Next build reads it directly, and scoped the block to new accounts and new addresses only. Also removed an obsolete CI workflow and tightened phone-with-country-code expectations across tests.
