Sunday work day. Most of the effort landed across four parallel worktrees of the same product, which is becoming my normal rhythm: one feature, several branches cooking in isolation, merged into a single PR.

### Backoffice: VGR Admins screen

Pulled the platform admin management out of the generic Users list and gave it its own screen. Mixing a global user CRUD with a privileged flag like `plataforma_admin` was asking for an accidental grant, so a dedicated screen with explicit grant/revoke flows felt safer and clearer. Shipped as PR #905.

### Financial module docs

Expanded the implementation manual with the Financial screens, using the seeded mirror as the source of truth for the walkthrough. First pass covered the headline screens, but accounts payable, accounts receivable, and the rest of the module were missing, so I went back and filled the gaps.

### Database reset script

Side quest: wrote a prod reset script that keeps only the admin user plus the state and municipality tables. Hit a Postgres syntax error around position 327, a stray backslash from copy-paste. Fixed and moved on.

### OAuth integration

Also walked through a Conta Azul OAuth authorization URL to understand what the authorization code callback actually needs from our side. Nothing to ship yet, just mapping the flow.
