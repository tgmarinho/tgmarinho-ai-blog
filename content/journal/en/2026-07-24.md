Today was a heavy day of turning scattered decisions into shipped foundations and written conventions across a Next.js 16 offline-first PWA.

### PWA foundation and stack
Landed the Phase 1 fundamentals: Serwist-based PWA shell, protected layout with bottom nav and a connectivity strip, auth flows (login and change password), Dexie schema, TanStack Query provider, and a Zustand-backed sync store. Documented a non-trivial call: keep Turbopack for dev speed but force `next build --webpack` in production so Serwist stays on its stable path, avoiding the experimental Turbopack adapter.

### Features and data flow
Shipped the Phase 2 dashboard, sync engine, and the report wizard, including a per-price-table selector. Ported masks and money utilities instead of pulling more libraries, and added Supabase CLI config plus initial migrations.

### Conventions and tickets
Standardized `useSuspenseQuery` for Dexie reads in display hooks, adopted `react-select` with a `SelectField` wrapper for RHF plus Zod, and normalized arbitrary Tailwind `px-*` classes to design tokens. Wrote ADRs, PRDs per screen, and 15 implementation tickets for Phase 3, including an XState refactor for the sync engine and E2E test coverage.

### Tooling
Migrated CI to Bun and Node 24. Also started a small skill to catalog useful GitHub repos on demand, so inspiration and references stop drifting away between sessions.
