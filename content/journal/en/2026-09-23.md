Today was a mix of shipping product changes, tightening the test pipeline, and clearing friction from local onboarding across a few workspaces.

### Operational role rework
Landed a breaking change replacing the legacy "helper" registration with a first-class operational "Auxiliary" function. The idea is to let managers attach one or more auxiliaries to an activity plan the same way they attach a technician, with a commission percentage carried as a snapshot into future stages. I also pushed a WIP reference commit for cross-company group registrations to unblock the next iteration.

### E2E environment
Spent real time getting end-to-end tests deterministic. Moved E2E onto a dedicated, isolated database so runs stop polluting the shared dev state, fixed a `VITE_API_URL` misconfiguration that was silently dropping the `/api` suffix, and updated stale landing and backoffice assertions. Also removed a few Biome suppressions in the seed script that were no longer doing anything.

### Local dev + docs
On another project, I set up a Postgres container that supports UUIDv7, wired up a reset-migrate-seed flow so a fresh clone reproduces exactly what CI would build, and documented how to run E2E in the README. Closed the day by publishing a security best-practices audit report.

Small commits, big compounding wins on reliability.
