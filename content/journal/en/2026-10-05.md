A heavy day across several workspaces, mostly polishing an agricultural platform and finishing an infrastructure migration.

### Agricultural platform (multi-workspace)

The area-divergence alert on activity conferral got the most attention. I removed the noisy "0%" case and the "waiting for estimated value" message from the schedule view, then simplified the alert copy itself and applied review feedback. A fixture for the conferral test suite was completed after a main merge so `combustivel_litros` lines up again.

On the financial side, I shipped a feature where accounts receivable can carry a default category and a dedicated financial account per installment, with the API accepting that per-parcel shape. I also catalogued the product's features by category and wrote guidance on isolating Postgres per workspace, which has been on my mind as I try more parallel-agent workflows.

Across the parallel worktrees I triaged open PRs and issues, closed a stale one with a comment, and merged main down into feature branches.

### Internal web app

Finished the long MongoDB-to-Postgres cutover: imported production data into Postgres (PR #471), documented the day-of procedure (freeze the VPS, start from an empty DB), fixed dev-server rendering for emails and PDFs, cleaned old Vercel and Railway leftovers, and tightened a login-page notice plus a long form-header overflow.

### Side exploration

Sketched an MVP for a small live-meeting tool, scoped at ~5 rooms and ~1k viewers a day, with screen share in scope.
