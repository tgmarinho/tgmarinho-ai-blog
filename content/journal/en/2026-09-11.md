Today was split between a new personal RAG project and a batch of small infra moves across the agro workspaces.

### amarillo-v1 (Bible RAG)
This was the main build of the day. I laid the foundation: docker with Postgres + pgvector, a typed config layer, and the initial schema. Then I moved fast: PT ingestion with lexical search per verse (FTS), followed by the embeddings pipeline and hybrid search using Reciprocal Rank Fusion. I also wrote the architecture doc, README, and set up `AGENTS.md` (with `CLAUDE.md` as a symlink). The goal is a very fast search where I can ask for every reference tied to a concept like "glory" and get all the passages back, ranked well.

### santo-domingo
Kicked off a spike combining Bun, oRPC, Drizzle, and React/Vite. I also wanted a small script to cleanly stop Bun processes, mirroring a helper I already use elsewhere.

### canberra-v2, hong-kong-v4, st-georges, vancouver-v1
Mostly Railway preview environments and a design conversation around modeling snapshot commission percentages on activity plans, plus clarifying the difference between chart-of-accounts categories and cost centers. Small commits, but the modeling discussion was the real output.

Feels good to plant a new project while keeping the existing ones moving.
