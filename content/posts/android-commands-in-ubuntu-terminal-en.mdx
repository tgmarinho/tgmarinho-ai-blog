Hey, below for reference are some commands from the **tools** and **platform-tools** folders that I added to the PATH as taught in the [previous post](http://tgmarinho.wordpress.com/2011/12/30/configurando-as-pastas-android-sdk-no-path-do-ubuntu-11-04/ "Android PATH").
``$adb version`` As the name says, it lists the version; the output of this command in the console is: ``tgmarinho@tgmarinho:~$ adb version Android Debug Bridge version 1.0.29 tgmarinho@tgmarinho:~$ **$android**`` This command opens the AVD - Android Virtual Device configuration window; in this program you update the AVD, create an emulator, etc.:  **$android list targets** This command lists all your available Android devices; in my console I get the following output, since I installed every possible one:  Note: This list isn't complete, there's more below, but it isn't shown. Pay attention to the ID — with the ID in hand we can create an AVD passing parameters in the Ubuntu console. **$android create avd -n <name> -t <id> -c <sd\_card\_size>M -s ** This command <with\_parameters\_here> creates an AVD emulator for you. Here's the real example:  First I listed to see which AVDs I had available using the command already shown, $ android list targets, and from there I grabbed the ID of my latest AVD, ID=14. Then I ran the following command: **$ android create avd -n any\_name -t 14 -c 256M** I created an AVD emulator named: any\_name, with ID = 14 (i.e., emulator Based on Android 2.2 (API level 8)), with 256M of storage capacity, and pressed enter, getting the following output: Auto-selecting single ABI armeabi-v7a Created AVD 'any\_name' based on Google APIs (Google Inc.), ARM (armeabi-v7a) processor, with the following hardware config: hw.lcd.density=240 vm.heapSize=48 hw.ramSize=512 And finally, to launch the recently created emulator, we run the following command: **$emulator -avd any\_name**  Simple, right? To start the emulator just pass the name of the emulator you created. The emulator takes a long time to load (1 to 2 minutes), since it boots an operating system. The tip from [Ricardo Lecheta](http://www.livroandroid.com.br/ "Ricardo Lecheta, author of the Google Android book") is to always leave the emulator open, since you can install or view new apps in the emulator without closing it. \[UPGRADE\] Command to install an application you downloaded or developed: user@user**:**~/Documentos/eclipse/<span style="text-decoration:underline;">android-sdk-linux\_x86/platform-tools</span>$ **adb install /home/tgmarinho/Downloads/BarcodeScanner3.6.apk** Notes: I'm inside the android-sdk-linux/platform-tools folder and I run the **adb install** command passing the path to the **application.apk**. NOTE: The emulator needs to be running; after executing the command, check whether the APP is installed. \[UPGRADE\] I think that's it!
