Baixe o NodeJS: [https://nodejs.org/en/download/](https://nodejs.org/en/download/)

Descompacte o archive binário em qualquer diretório onde você queira instalar o Node. Eu uso `/usr/local/lib/nodejs`

```
sudo mkdir /usr/local/lib/node
```

```
sudo tar -xJvf node-v8.9.4-linux-x64.tar.xz
```

```
sudo mv /usr/local/lib/node/node-v8.9.4-linux-x64 /usr/local/lib/node/nodejs
```

Configure a variável de ambiente em `~/.profile`, adicionando o trecho abaixo ao final do arquivo.

```
# Nodejs
export NODEJS_HOME=/usr/local/lib/node/nodejs
export PATH=$NODEJS_HOME/bin:$PATH
```

Recarregue o profile

`. ~/.profile`

Teste a instalação com

```
$ node -v
```

```
$ npm version
```
