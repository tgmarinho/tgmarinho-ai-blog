1. Overview

Statically-generated personal site. Institutional pages, a 70+ MDX blog with fuzzy search, a bilingual daily journal auto-generated from Claude Code sessions, and three lightweight API routes. Philosophy: content-first → build-time pipeline (Velite) → static-first rendering → progressive enhancement.

4. Content Pipeline (Velite)

Two collections, both s.markdown() (pre-rendered HTML, no JSX in body).

Post content/posts/**/*.mdx

title · description · date · published · slug? · language · translationKey · categories · image · body · plainBody (stripped, for search)

JournalEntry content/journal/{pt-BR,en}/*.md

title · summary · date · repos · commits · sessions · language · body. Slug from filename. URL: /daily/<slug> or /en/daily/<slug>.

Import convention

import { posts, journalEntries, type Post } from "#site/content";
import { sortPostsByDate, getAllCategories } from "@/lib/velite";

6. i18n

  • Strategy: next-intl with [locale] segment. pt-BR is the default (no prefix), en under /en.
  • UI messages: messages/{pt-BR,en}.json.
  • Posts pair via language + translationKey. Detail page surfaces a switch.
  • Audits: npm run audit:i18n-seo and npm run audit:refs.

9. Automations — Daily Journal

Local-only pipeline (reads ~/.claude/projects/*/*.jsonl). LaunchAgent com.tgmarinho.journal.daily @ 23:00 America/Campo_Grande.

raw bullets (daily-journal.mjs)
  → narrate pt-BR (claude CLI)
  → narrate en   (claude CLI)
  → append footer
  → commit on branch journal/<DATE>
  → push + open draft PR (manual review gate)

Privacy boundaries

  • Default exclude repos (substring): private, finance, health
  • Extend via JOURNAL_EXCLUDE_REPOS=clientx,clienty
  • Narrator prompt forbids: people, job applications, credentials, client data, undisclosed security bugs
  • If session leaks something sensitive: filter silently, never comment on the leak

10. Decisions (ADR-light)

  • Velite > MDX runtime — performance + type safety beat in-post JSX.
  • No CMS — content in Git, reviews via PR.
  • Static-first — 90% SSG, APIs are the exception.
  • Editorial fonts scoped to .prose — loaded per route layout, not globally.
  • In-memory APIs are provisional — flagged // TODO on purpose.
  • Daily journal is local-only by design — session files don't exist in CI.

Anti-patterns (don't)

  • Swap Velite for contentlayer / next-mdx-remote.
  • Add <Callout/> inside posts (body is s.markdown()).
  • Recreate shadcn components via CLI when an equivalent exists in src/components/ui/.
  • Use Fraunces / Source Serif 4 outside .prose.
  • Add useEffect for data fetching in RSCs.
